# Antigravity Extension Tools List

This document lists all tools available in the **Antigravity** pyRevit extension.

| Tool Name | Type | Group / Location | Description |
| :--- | :--- | :--- | :--- |
| **Save** | Pushbutton | Master > Snapshots | Save Visibility State |
| **Load** | Pushbutton | Master > Snapshots | Load Visibility State |
| **Delete** | Pushbutton | Master > Snapshots | Delete Visibility State |
| **Search** | Pushbutton | Master | Search & Toggle Categories |
| **ResetAll** | Pushbutton | Master | Unhide All Architecture |
| **Toggle Walls** | Pushbutton | Model Categories | Toggle Walls |
| **Toggle Doors** | Pushbutton | Model Categories | Toggle Doors |
| **Toggle Windows** | Pushbutton | Model Categories | Toggle Windows |
| **Toggle Furniture** | Pushbutton | Model Categories | Toggle Furniture |
| **Toggle Floors** | Pushbutton | Model Categories | Toggle Floors |
| **Toggle Roofs** | Pushbutton | Model Categories | Toggle Roofs |
| **Toggle Ceilings** | Pushbutton | Model Categories | Toggle Ceilings |
| **Toggle Columns** | Pushbutton | Model Categories | Toggle Columns |
| **Toggle Structural Columns** | Pushbutton | Model Categories | Toggle Structural Columns |
| **Toggle Stairs** | Pushbutton | Model Categories | Toggle Stairs |
| **HideAllAnno** | Pushbutton | Annotation | Hide All Annotations |
| **UnhideAllAnno** | Pushbutton | Annotation | Unhide All Annotations |
| **Toggle Dimensions** | Pushbutton | Annotation | Toggle Dimensions |
| **Toggle Grids** | Pushbutton | Annotation | Toggle Grids |
| **Toggle Levels** | Pushbutton | Annotation | Toggle Levels |
| **Toggle Tags** | Pushbutton | Annotation | Toggle Tags |
| **Toggle Text Notes** | Pushbutton | Annotation | Toggle Text Notes |
| **HideLinks** | Pushbutton | Link Tools > Links | Hide All Links |
| **UnhideLinks** | Pushbutton | Link Tools > Links | Unhide All Links |
| **FixLinks** | Pushbutton | Link Tools > Links | Force Links to ByHostView |
| **Isolate** | Pushbutton | Link Tools | Isolate Selected Category |
| **Presets** | Pulldown | Link Tools | Apply Visibility Preset (Requires `presets.json`) |
